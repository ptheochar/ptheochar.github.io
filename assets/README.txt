# Favicon Pack for ptheochar.github.io

This pack contains a clean, professional monogram favicon for your site.

## Files
- `favicon.ico` (16, 32, 48)
- `favicon-16x16.png`
- `favicon-32x32.png`
- `apple-touch-icon.png` (180x180)
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `site.webmanifest`

## How to install (GitHub Pages)
1. Add all files to the root of your repository (the same folder as `index.html`).  
2. Add these tags inside the `<head>` of your site:

```html
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="manifest" href="/site.webmanifest">
<link rel="shortcut icon" href="/favicon.ico">
<meta name="theme-color" content="#0E1930">
```

That's it — commit and push to GitHub. Browsers will pick up the favicon automatically.
